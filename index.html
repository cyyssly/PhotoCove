    快速上手

    PhotoCove 是本地照片浏览工具：直接读你指定的文件夹，不搬动、不改写任何照片；索引与缩略图存在程序目录的 data\ 里。

    1. 到 设置 点「＋ 添加图片库目录」，选一个照片文件夹。可以添加多个，子文件夹会自动识别为相册。
    2. 点该目录右侧的「扫描」。首次会为每张照片读一段文件头（不解码像素），两万张的量级以分钟计。
    3. 回到 作品集 浏览。之后每次打开都直接显示上次的结果，不会自动扫描。

    扫描期间右下角有进度浮卡，可随时取消，已扫的部分照常入库。要更新时点对应目录的「扫描」，或在「设置 → 维护」里全量重新扫描。

    • 筛选栏（年份 / 器材 / 相册）对作品集、时间轴、相册集、地图都生效
    • 每个视图每批渲染 36 张，滚到底自动追加，几万张也能秒开

    • 顶栏右侧在滚动超过 3 屏后出现「↑ 返回顶端」

    地图与补 GPS

    底图用免 API Key 的 OpenStreetMap 瓦片，随程序本地存放，多源自动降级（osm.de → osm.org → OpenTopoMap）。三者都是 Web 墨卡托 / WGS-84，与照片经纬度一致、无偏移。瓦片请求只发送瓦片坐标，不上传照片、文件名或经纬度。地名搜索与瓦片需要联网，其余功能离线可用。

    批量补坐标

    1. 地图页左下角点「N 张照片无位置信息」，面板按文件夹聚合（一次最多列 200 张，避免节点过多卡顿）。
    2. 点一个文件夹，应用内打开编辑器，只载入该文件夹里缺 GPS 的照片，已有坐标的不会被覆盖。
    3. 在图上点一下取坐标（标记可拖动微调），或输入地名搜索。搜索走 OpenStreetMap 的 Nominatim，返回 WGS-84，与照片和底图同一坐标系，不需要 GCJ-02 / BD-09 纠偏。
    4. 左侧全选或单选，点「写入」。写完成片会立即刷新网格、地图与索引。

    关于写入

    • 这是程序唯一会改动照片的操作。写入的是 EXIF 里的 GPS 坐标，其余字段不动。
    • 写入前自动把原图备份到 data\gps-backup\（镜像原路径），出问题可以还原。这里故意不用 exiftool 的 _original 同目录备份：那会在你的照片文件夹里多出 xxx_original.jpg，下次扫描被当成新照片索引进来。
    • 写入由 exiftool 完成。没装时编辑器会提示，点「指定 exiftool」选一次即可，之后记住。

    GPSStamp 备用入口

    文件夹行尾的 ↗ 会用同目录下的 GPSStamp 打开该文件夹（只载入缺 GPS 的照片）。对 RAW / HEIC 更稳，也可以单独使用，详见 GPSStamp\使用说明.txt。

    数据与迁移

    索引和缩略图都在程序目录的 data\ 里，原图始终留在你指定的文件夹中，不会被移动或修改。

    • 只有程序目录不可写时（例如放进 Program Files），才会退回系统的 %APPDATA%\PhotoCove；「设置 → 维护 → 存储状态」里会显示实际位置。
    • 目录行显示「不可用」通常只是外接盘没插、或文件夹被改名挪走了。插回盘后点「重新检查」即可，不必重新添加。

    格式支持

    • 常见格式：JPEG / PNG / WebP / GIF / TIFF，直接解码显示。
    • RAW（CR2 / CR3 / ARW / NEF / ORF / DNG 等）：默认关闭，需到设置里开启。开启后通过提取相机内嵌的 JPEG 预览图展示，不解码原始传感器数据；开启之前已扫描过的 RAW 需点「重建 RAW 索引」。
    • HEIC / HEIF：暂不支持。Chromium 内核不解这个格式，要另接 libheif。

    已知限制

    • 没有代码签名：exe 首次运行时 Windows SmartScreen 会拦一次，点「更多信息 → 仍要运行」即可，同一台机器放行一次后不再提示。用 U 盘或局域网拷贝过来的文件不带网络标记，通常连提示都没有。
    • 不自动监视文件夹：新加的照片需要手动「扫描」才进索引，之后走增量（比对修改时间 + 文件大小），只读变化的文件。
    • 首次扫描较慢：每张照片都要读一段文件头，两万张以分钟计；这是唯一一次性的开销。
    • 地图页最多列 200 张无位置照片：套图或截图特别多时分批处理，补完再点一次即可。

    常见问题

    打开后一张照片都没有？

    程序不会自动扫描。先确认筛选栏没把照片筛掉（年份 / 器材 / 相册都选「全部」），再到设置里给目录点一次「扫描」。若是新换的电脑，索引不会跟着照片走，需要重扫一次——除非你把 data\ 一起拷过来了。

    缩略图一直是灰块或转圈？

    单张解码有 20 秒上限，超时会显示「加载超时 · 点击重试」。整片空白时，先看设置页目录徽章是不是「不可用」（盘没插、文件夹被改名），插回盘后点「重新检查」会自动恢复。

    索引到的照片比文件夹里少？

    只索引支持的图片格式，见「格式支持」。RAW 未开启时不计入；隐藏文件、非图片文件也会被跳过。

    换电脑要做什么？

    整个程序目录（含 data\）拷过去，照片留在原来的盘位即可，不用重扫。若照片路径变了，把旧的目录记录移除、重新添加扫描一次。

    补 GPS 会改动我的原图吗？

    会，但只改 EXIF 里的 GPS 坐标，并且写入前先备份到 data\gps-backup\。除此之外的所有操作都是只读的：扫描、生成缩略图、浏览都不会修改照片文件。

    能在浏览器里打开吗？

    不能。程序需要直接读写磁盘和调用 exiftool，浏览器沙箱做不到。直接双击 index.html 只会看到一张「请从桌面窗口启动」的引导页。
