    快速上手

    PhotoCove 是本地照片浏览工具：直接读你指定的文件夹，不搬动、不改写任何照片；索引与缩略图存在程序目录的 data\ 里。

    1. 到 设置 点「＋ 添加目录」，选一个照片文件夹。可以添加多个，子文件夹会自动识别为相册。
    2. 选完立刻开始扫描。首次会为每个文件读一小段文件头（不解码像素），几万张通常半分钟以内。
    3. 回到 作品集 浏览。之后每次打开都直接显示上次的结果，不会自动扫描。

    扫描期间右下角有进度浮卡，可随时取消，已扫的部分照常入库。之后新增或改动过照片，点对应目录的「重新扫描」即可增量更新。

    地图与补 GPS

    底图用免 API Key 的 OpenStreetMap 瓦片，随程序本地存放，多源自动降级（osm.de → osm.org → OpenTopoMap）。三者都是 Web 墨卡托 / WGS-84，与照片经纬度一致、无偏移。瓦片请求只发送瓦片坐标，不上传照片、文件名或经纬度。地名搜索与瓦片需要联网，其余功能离线可用。

    在地图上找位置

    地图页左上角可以直接搜地名：回车或点「搜索」，候选里用 ↑ ↓ 选择、回车定位；搜索框右边就是放大 / 缩小按钮。也可以直接在地图上点一下落下标记，标记可拖动微调；右下角显示当前坐标，点「清除」或按 Esc 收起。右下角这条坐标也是补位置工作台的取点处：查坐标时点一下地图就有；打开右侧待处理列表后，同一个选点直接用于批量写入（见下一节）。

    给照片补坐标

    1. 地图页右上角点「N 张照片无位置信息」，这一行就在原地向下展开成相册列表（按相册聚合，细分粒度与设置页的「相册识别」一致，相册按名字顺序排列，不提供自定义排序），面板右上角的 ▴ 收起后恢复成一行。点一个相册，右侧就出现待处理列表（按文件名顺序排列），只载入该相册里缺 GPS 的照片，已有坐标的不会被覆盖；列表工具行最右端是三个图标按钮：返回箭头退回相册列表接着挑下一个，列表 / 缩略图 切换右栏显示样式（缩略图每行两张、正方形裁切，横图竖图都不变形）。
    2. 地图会先落到同相册里已有 GPS 照片的大致位置，省得从全国视图开始找；同相册一张带位置的照片都没有时，就从当前视野开始。
    3. 在图上点一下取坐标（标记可拖动微调），或搜地名定位。搜索走 OpenStreetMap 的 Nominatim，返回 WGS-84，与照片和底图同一坐标系，不需要 GCJ-02 / BD-09 纠偏。
    4. 右栏全选或单选，点「写入 N 张」。写完后这些照片立刻变成地图上的实心点，并从待处理列表里消失。
    5. 按 Esc 或右栏右上角的 × 退出补位置；「清除」只清坐标、保留列表，适合同一个相册换个位置再写一批。

    关于写入

    • 这是程序唯一会改动照片的操作。写入的是 EXIF 里的 GPS 坐标，其余字段不动。
    • 写入过的坐标会另外记一份：重新扫描、甚至「清空索引」后重建索引，这些照片仍会回到地图上的原位，不用重新补一次。RAW 尤其需要这道保险——exiftool 给 RAW 写坐标时把它追加到文件尾部，扫描读文件头是看不到的。
    • 写入前自动把原图备份到程序根目录的 backup\（开发版即 E:\www\JS\PhotoCove\backup\，按原路径镜像），出问题可以还原。这里故意不用 exiftool 的 _original 同目录备份：那会在你的照片文件夹里多出 xxx_original.jpg，下次扫描被当成新照片索引进来。
    • 写入由 exiftool 完成。没装时右栏底部会提示，点「指定 exiftool」选一次即可，之后记住。

    数据与迁移

    索引和缩略图都在程序目录的 data\ 里，原图始终留在你指定的文件夹中，不会被移动或修改。

    「清空索引」全部删除，点「重新扫描」重建；补写的 GPS 坐标保留并自动回填不受影响

    • 目录行显示「不可用」通常只是外接盘没插、或文件夹被改名挪走了。插回盘后点该目录的「重新扫描」即可，不必重新添加。

    格式支持

    • 常见格式：JPEG / PNG / WebP / GIF / TIFF，直接解码显示。
    • RAW（CR2 / CR3 / ARW / NEF / ORF / DNG 等）：默认关闭，需到设置里开启。开启后通过提取相机内嵌的 JPEG 预览图展示，不解码原始传感器数据；开启之前已扫描过的 RAW 需点「重建 RAW 索引」。RAW 文件头里的 EXIF（机型、拍摄时间、光圈、ISO、GPS）同样会读取，供时间轴、器材筛选和地图点位使用；旧索引里的 RAW 缺这些字段，点一次「重新扫描」即可补齐（只需多读这一次）。部分老机型（如 RW2）本身不写标准 EXIF，读不到属正常。
    • HEIC / HEIF：暂不支持。Chromium 内核不解这个格式，要另接 libheif。

    已知限制

    • 没有代码签名：exe 首次运行时 Windows SmartScreen 会拦一次，点「更多信息 → 仍要运行」即可，同一台机器放行一次后不再提示。用 U 盘或局域网拷贝过来的文件不带网络标记，通常连提示都没有。
    • 不自动监视文件夹：新加的照片需要手动「重新扫描」才进索引，之后走增量（比对修改时间 + 文件大小），只读变化的文件。
    • 首次扫描较慢：每个文件都要读一小段文件头（不解码像素），几万张通常半分钟以内；这是唯一一次性的开销，之后只比对修改时间与大小。
    • 地图页最多列 200 张无位置照片：套图或截图特别多时分批处理，补完再点一次即可。

    常见问题

    打开后一张照片都没有？

    程序不会自动扫描。先确认筛选栏没把照片筛掉（年份 / 器材 / 相册都选「全部」），再到设置里给该目录点一次「重新扫描」。若是新换的电脑，索引不会跟着照片走，需要重扫一次——除非你把 data\ 一起拷过来了。

    缩略图一直是灰块或转圈？

    单张解码有 20 秒上限，超时会显示「加载超时 · 点击重试」。整片空白时，先看设置页目录徽章是不是「不可用」（盘没插、文件夹被改名），插回盘后点该目录的「重新扫描」会自动恢复。

    索引到的照片比文件夹里少？

    只索引支持的图片格式，见「格式支持」。RAW 未开启时不计入；隐藏文件、非图片文件也会被跳过。

    换电脑要做什么？

    整个程序目录（含 data\）拷过去，照片留在原来的盘位即可，不用重扫。若照片路径变了，把旧的目录记录移除、重新添加一次。

    补 GPS 会改动我的原图吗？

    会，但只改 EXIF 里的 GPS 坐标，并且写入前先备份到程序根目录的 backup\。除此之外的所有操作都是只读的：扫描、生成缩略图、浏览都不会修改照片文件。

    能在浏览器里打开吗？

    不能。程序需要直接读写磁盘和调用 exiftool，浏览器沙箱做不到。直接双击 index.html 只会看到一张「请从桌面窗口启动」的引导页。
